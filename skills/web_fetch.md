# Skill: web_fetch

## Description

Fetch the textual content of a specific URL.

## Parameters

- `url` (string): The complete URL of the website to fetch.

## Steps

1. **Step: web_fetch**
    - `url`: `{{url}}`
    - **Output:** `fetched_content`

2. **Output**
    - **Value:** 
```
Content from {{url}}:

{{fetched_content}}
```
